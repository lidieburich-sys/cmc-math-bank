## 题目

称实函数 $`f`$ 满足条件 $`(P)`$，若它在 $`[0,1]`$ 上非负连续，$`f(1)>f(0)=0`$，$`\int_0^1dx/f(x)=+\infty`$，且


```math
f((x_1+x_2)/2)\ge[f(x_1)+f(x_2)]/2\quad(x_1,x_2\in[0,1]).
```


（1）设 $`c>0`$，对 $`f_1(x)=cx,f_2(x)=\sqrt x`$，分别判断是否满足 $`(P)`$，并计算对固定 $`m\ge1`$ 的极限


```math
\lim_{x\to0^+}[f_i(x)-xf_i'(x)]^m e^{f_i'(x)}\quad(i=1,2).
```


（2）证明存在满足 $`(P)`$ 的函数 $`f`$ 和趋于零的正数列 $`x_n`$，使 $`f`$ 在每个 $`x_n`$ 可导，并对任意固定 $`m\ge1`$，


```math
[f(x_n)-x_nf'(x_n)]^m e^{f'(x_n)}\longrightarrow+\infty.
```

<details>
<summary>展开参考解答</summary>

（1）$`f_1`$ 满足 $`(P)`$，且 $`f_1-xf_1'=0`$，极限为 $`0`$。$`f_2`$ 连续、非负且凹，但 $`\int_0^1x^{-1/2}dx=2`$，故不满足 $`(P)`$。其极限为


$`\displaystyle \lim_{x\to0^+}(\sqrt x/2)^m e^{1/(2\sqrt x)}=+\infty.`$


（2）构造 $`a_1=1`$，并递推


$`\displaystyle a_{n+1}=a_n\exp[-2/(n\sqrt{a_n})].`$


显然 $`a_n\downarrow0`$。令 $`f`$ 为依次连接 $`(a_n,\sqrt{a_n})`$ 的折线，$`f(0)=0`$。在 $`(a_{n+1},a_n)`$ 上斜率为


$`\displaystyle k_n=\frac1{\sqrt{a_n}+\sqrt{a_{n+1}}}.`$


这些斜率随 $`x`$ 增加而递减，故折线凹，且非负连续、$`f(1)=1`$。并且


$`\displaystyle \int_{a_{n+1}}^{a_n}\frac{dx}{f(x)}=\frac1{2k_n}\ln\frac{a_n}{a_{n+1}}\ge\frac1n,`$


所以反常积分发散，$`(P)`$ 成立。

任取 $`x_n\in(a_{n+1},a_n)`$。有 $`f'(x_n)=k_n\ge1/(2\sqrt{a_n})`$，且


$`\displaystyle f(x_n)-x_nf'(x_n)=\frac{\sqrt{a_na_{n+1}}}{\sqrt{a_n}+\sqrt{a_{n+1}}}\ge\frac{\sqrt{a_n}}2e^{-1/(n\sqrt{a_n})}.`$


因此所求表达式至少为


$`\displaystyle \left(\frac{\sqrt{a_n}}2\right)^m\exp\left[\frac{1/2-m/n}{\sqrt{a_n}}\right].`$


对固定 $`m`$，充分大的 $`n`$ 有 $`1/2-m/n\ge1/4`$，指数增长压倒 $`a_n^{m/2}`$，故该下界趋于无穷。
