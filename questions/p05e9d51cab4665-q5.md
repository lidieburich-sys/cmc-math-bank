## 题目

把 $`x\in\mathbb R`$ 写成十进制展开


```math
x=\sum_{n=0}^{\infty}\frac{x_n}{10^n},
```


其中 $`x_0\in\mathbb Z`$，$`x_n\in\{0,1,\ldots,9\}`$（$`n\ge1`$）。除一个零测集外，表示唯一。定义


```math
\varphi_n(x)=\begin{cases}1,&x_n\text{ 为偶数},\\-1,&x_n\text{ 为奇数}.\end{cases}
```


证明：若 $`f\in L^1(\mathbb R)`$，则


```math
\lim_{n\to\infty}\int_{\mathbb R}f(x)\varphi_n(x)\,dx=0.
```

<details>
<summary>展开参考解答</summary>

$`\varphi_n`$ 在长度为 $`10^{-n}`$ 的相邻小区间上依次取 $`1,-1`$，一对区间上的积分为零，且 $`|\varphi_n|=1`$ 几乎处处。因此任意有界区间 $`[a,b]`$ 都有


```math
\left|\int_a^b\varphi_n(x)\,dx\right|\le2\cdot10^{-n}\longrightarrow0.
```


故结论对有限个有界区间示性函数的线性组合成立。这样的阶梯函数在 $`L^1(\mathbb R)`$ 中稠密。给定 $`\varepsilon>0`$，取阶梯函数 $`s`$ 使 $`\|f-s\|_1<\varepsilon`$，则


```math
\left|\int_{\mathbb R}f\varphi_n\right|
\le\|f-s\|_1+\left|\int_{\mathbb R}s\varphi_n\right|.
```


取上极限得不超过 $`\varepsilon`$，再令 $`\varepsilon\downarrow0`$，即得结论。

</details>
