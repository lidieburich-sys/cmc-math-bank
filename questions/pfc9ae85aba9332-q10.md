## 题目

给定 $`x_0>y_0>0`$，对 $`n\ge0`$ 归纳定义


```math
x_{n+1}=\frac1{2(n+1)}\sum_{k=0}^n(x_k+y_k),\qquad y_{n+1}=\left(\prod_{k=0}^nx_ky_k\right)^{1/(2n+2)}.
```


证明：（1）$`x_n-y_n\to0`$；（2）$`n(x_n-y_n)`$ 收敛于一个正数。

<details>
<summary>展开参考解答</summary>

由定义可化为


```math
x_{n+1}=\frac{(2n+1)x_n+y_n}{2n+2},\qquad y_{n+1}=x_n^{1/(2n+2)}y_n^{(2n+1)/(2n+2)}.
```


加权算术几何平均不等式及 $`x_n>y_n`$ 归纳给出


```math
x_n>x_{n+1}>y_{n+1}>y_n>0.
```


故 $`x_n\downarrow X`$、$`y_n\uparrow Y>0`$，且 $`X\ge Y`$。若 $`X>Y`$，则


```math
\ln\frac{y_{n+1}}{y_n}=\frac1{2n+2}\ln\frac{x_n}{y_n}\sim\frac{\ln(X/Y)}{2n},
```


其和发散，与 $`y_n\to Y`$ 矛盾。因此 $`X=Y`$，证明（1）。

令 $`\delta_n=x_n-y_n>0`$、$`p=1/(2n+2)`$。Taylor 公式对 $`(1+u)^p`$ 的余项给出（$`n\ge1`$）


```math
\delta_{n+1}=\frac n{n+1}\delta_n+R_n,\qquad0<R_n\le\frac{\delta_n^2}{4(n+1)y_0}.
```


故 $`h_n=n\delta_n`$ 严格递增，且


```math
1<\frac{h_{n+1}}{h_n}\le1+\frac{\delta_n}{4y_0n}.
```


由 $`\delta_n\to0`$，充分大时右端不超过 $`1+1/(2n)`$，乘积估计得 $`h_n=O(\sqrt n)`$，即 $`\delta_n=O(n^{-1/2})`$。于是 $`\sum\delta_n/n<\infty`$，上式又说明 $`h_n`$ 有界。正的单调数列 $`h_n`$ 因而收敛于 $`L\in(0,\infty)`$，证明（2）。

</details>
