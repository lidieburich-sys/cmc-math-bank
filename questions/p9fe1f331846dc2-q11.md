## 题目

给定分割 $`a=x_0<x_1<\cdots<x_n=b`$。记 $`S[a,b]`$ 为在整个区间上二阶连续可导、且在各小区间 $`[x_i,x_{i+1}]`$ 上均为次数不超过三次的实多项式的函数全体。证明：

（1）对任意实函数 $`f:[a,b]\to\mathbb R`$，恰有一个 $`s\in S[a,b]`$ 满足


```math
s(x_i)=f(x_i)\quad(i=0,1,\ldots,n),\qquad s''(a)=s''(b)=0.
```



（2）若另有 $`f\in C^2[a,b]`$，则上述插值函数满足


```math
\int_a^b [s''(x)]^2\,dx\le\int_a^b [f''(x)]^2\,dx,
```


且取等号的充要条件为 $`s=f`$ 在 $`[a,b]`$ 上恒成立。

<details>
<summary>展开参考解答</summary>

（1）令 $`h_i=x_{i+1}-x_i>0`$、$`f_i=f(x_i)`$，并以 $`M_i=s''(x_i)`$ 表示待定的节点二阶导数。先令 $`M_0=M_n=0`$。对 $`i=1,\ldots,n-1`$，解方程组


```math
h_{i-1}M_{i-1}+2(h_{i-1}+h_i)M_i+h_iM_{i+1}=6\left(\frac{f_{i+1}-f_i}{h_i}-\frac{f_i-f_{i-1}}{h_{i-1}}\right).
```


关于 $`M_1,\ldots,M_{n-1}`$ 的系数矩阵严格按行对角占优，因而可逆，解唯一。若 $`n=1`$，没有内部未知量，直接取 $`M_0=M_1=0`$。

在 $`[x_i,x_{i+1}]`$ 上定义


```math
\begin{aligned}s_i(x)={}&\frac{M_i(x_{i+1}-x)^3}{6h_i}+\frac{M_{i+1}(x-x_i)^3}{6h_i}\\&+\left(f_i-\frac{M_i h_i^2}{6}\right)\frac{x_{i+1}-x}{h_i}+\left(f_{i+1}-\frac{M_{i+1}h_i^2}{6}\right)\frac{x-x_i}{h_i}.\end{aligned}
```


它满足 $`s_i(x_i)=f_i`$、$`s_i(x_{i+1})=f_{i+1}`$，且


```math
s_i''(x)=M_i\frac{x_{i+1}-x}{h_i}+M_{i+1}\frac{x-x_i}{h_i}.
```


所以函数值和二阶导数在内节点左右相同；上面的三对角方程恰好保证 $`s_{i-1}'(x_i)=s_i'(x_i)`$。由此拼成 $`s\in C^2[a,b]`$，满足所有条件，存在性成立。反过来，任何满足条件的样条都必须具有这个分段表达式，且其 $`M_i`$ 必满足同一方程组，故唯一。

（2）记 $`g=f-s`$，则 $`g\in C^2[a,b]`$，且 $`g(x_i)=0`$。每段上 $`s_i'''`$ 是常数，分段积分分部得


```math
\begin{aligned}\int_a^b s''g''\,dx&=\sum_{i=0}^{n-1}\left([s_i''g']_{x_i}^{x_{i+1}}-s_i'''[g]_{x_i}^{x_{i+1}}\right)\\&=[s''g']_a^b=0.\end{aligned}
```


第二项因节点上 $`g=0`$ 消失，内节点边界项因 $`s''`$、$`g'`$ 连续相消，外端点项因 $`s''(a)=s''(b)=0`$ 消失。因此


```math
\int_a^b(f'')^2\,dx=\int_a^b(s'')^2\,dx+\int_a^b(g'')^2\,dx\ge\int_a^b(s'')^2\,dx.
```


若等号成立，由 $`g''`$ 连续知 $`g''\equiv0`$，所以 $`g`$ 是一次或常数函数；又 $`g(a)=g(b)=0`$ 且 $`a<b`$，故 $`g\equiv0`$，即 $`f=s`$。反之 $`f=s`$ 时显然取等号。

</details>
