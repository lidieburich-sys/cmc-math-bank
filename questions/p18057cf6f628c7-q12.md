## 题目

设 $`p\ge2`$，$`X\sim N(0,\Sigma)`$ 为 $`p`$ 维随机向量，$`\Sigma`$ 正定；$`\varepsilon\sim N(0,\sigma^2)`$ 与 $`X`$ 独立，$`\sigma^2>0`$。设 $`\beta_0\in\mathbb R^p`$，$`Y=\operatorname{sgn}(X^T\beta_0+\varepsilon)`$，并定义


```math
\beta^*=\operatorname*{argmin}_{\beta\in\mathbb R^p}E(Y-X^T\beta)^2.
```


（1）给出 $`\beta^*`$ 的显式表示；

（2）证明 $`\operatorname{cov}(X,Y)=-2\operatorname{cov}(X,F(-X^T\beta_0))`$，其中 $`F`$ 为 $`\varepsilon`$ 的分布函数；

（3）证明正态条件期望公式


```math
E(\alpha^TX\mid\beta^TX)=\frac{\alpha^T\Sigma\beta}{\beta^T\Sigma\beta}\,\beta^TX\quad(\beta\ne0);
```



（4）证明 $`\beta^*`$ 与 $`\beta_0`$ 成比例，并求比例常数。

<details>
<summary>展开参考解答</summary>

（1）展开目标函数并求梯度，唯一极小值满足 $`\Sigma\beta^*=E(XY)`$。因 $`EX=0`$，


$`\displaystyle \boxed{\beta^*=\Sigma^{-1}\operatorname{cov}(X,Y)}.`$


（2）独立性给出 $`E(Y\mid X)=1-2F(-X^T\beta_0)`$，再乘 $`X`$ 取期望即可得到协方差等式。

（3）若 $`\beta\ne0`$，令 $`c=(\alpha^T\Sigma\beta)/(\beta^T\Sigma\beta)`$。$`W=\alpha^TX-c\beta^TX`$ 与 $`\beta^TX`$ 联合正态且协方差为零，因此独立、$`EW=0`$。故所给公式成立。原卷未排除 $`\beta=0`$；该情形条件期望直接为 $`E(\alpha^TX)=0`$，不使用零分母公式。

（4）令 $`Z=X^T\beta_0+\varepsilon`$，$`v=\beta_0^T\Sigma\beta_0+\sigma^2>0`$。由联合正态条件期望，


$`\displaystyle E(X\mid Z)=\frac{\Sigma\beta_0}{v}Z,\qquad E(XY)=\frac{\Sigma\beta_0}{v}E|Z|=\Sigma\beta_0\sqrt{\frac2{\pi v}}.`$


因此显式结果为


$`\displaystyle \boxed{\beta^*=\sqrt{\frac2{\pi(\beta_0^T\Sigma\beta_0+\sigma^2)}}\,\beta_0}.`$


此式也适用于 $`\beta_0=0`$。一般协方差情形必须保留 $`\beta_0^T\Sigma\beta_0`$，原参考答案最后的简化系数不适用于一般参数。

</details>
