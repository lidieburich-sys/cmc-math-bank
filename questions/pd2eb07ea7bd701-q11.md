## 题目

对初值问题 $`y'=f(x,y),y(x_0)=y_0`$，考虑三级 Runge–Kutta 方法


```math
y_{n+1}=y_n+h(c_1K_1+c_2K_2+c_3K_3),
```




```math
K_1=f(x_n,y_n),\quad K_2=f(x_n+a_2h,y_n+b_{21}hK_1),
```




```math
K_3=f(x_n+a_3h,y_n+b_{31}hK_1+b_{32}hK_2).
```


（1）确定使该方法为三阶的所有参数；（2）讨论稳定性。

<details>
<summary>展开参考解答</summary>

（1）Taylor 展开比较所有三阶项，全部阶条件为


```math
a_2=b_{21},\quad a_3=b_{31}+b_{32},\quad c_1+c_2+c_3=1,
```




```math
c_2a_2+c_3a_3=\frac12,\qquad c_2a_2^2+c_3a_3^2=\frac13,\qquad c_3b_{32}a_2=\frac16.
```


这些条件也是充分条件。令 $`u=a_2,v=a_3`$，所有实参数分为以下三类：

若 $`u\ne0,2/3`$，且 $`v\ne0,u`$，则


```math
c_2=\frac{3v-2}{6u(v-u)},\qquad c_3=\frac{2-3u}{6v(v-u)},\qquad c_1=1-c_2-c_3,
```




```math
b_{21}=u,\qquad b_{32}=\frac1{6uc_3},\qquad b_{31}=v-b_{32}.
```


若 $`u=v=2/3`$，则可任取 $`c_3\ne0`$，并令


```math
c_1=\frac14,\quad c_2=\frac34-c_3,\quad b_{21}=\frac23,\quad b_{32}=\frac1{4c_3},\quad b_{31}=\frac23-b_{32}.
```


若 $`u=2/3,v=0`$，则可任取 $`c_3\ne0`$，并令


```math
c_2=\frac34,\quad c_1=\frac14-c_3,\quad b_{21}=\frac23,\quad b_{32}=\frac1{4c_3},\quad b_{31}=-b_{32}.
```


这三类穷尽全部阶条件的解。例如 $`u=1/2,v=1`$ 给出经典 Kutta 参数 $`(c_1,c_2,c_3)=(1/6,2/3,1/6)`$、$`(b_{21},b_{31},b_{32})=(1/2,-1,2)`$。原参考答案只给了这一组，不能代表“所有参数”。

（2）对试验方程 $`y'=\lambda y`$，上述所有方法都有稳定函数


```math
R(z)=1+z+\frac{z^2}2+\frac{z^3}6,\qquad z=h\lambda.
```


绝对渐近稳定域为 $`\boxed{\{z\in\mathbb C:|R(z)|<1\}}`$。在负实轴上为 $`-\rho<z<0`$，其中 $`\rho>0`$ 满足 $`\rho^3-3\rho^2+6\rho-12=0`$（约2.5127）。

</details>
