## 题目

（1）证明方程 $`x^3-3x=t`$ 有三个在 $`[-2,2]`$ 上连续、在 $`(-2,2)`$ 内连续可微的解支 $`x=\varphi_1(t),\varphi_2(t),\varphi_3(t)`$，满足


```math
\varphi_1(-t)=-\varphi_3(t),\qquad \varphi_2(-t)=-\varphi_2(t).
```


（2）若 $`f`$ 是 $`[-2,2]`$ 上的连续偶函数，证明


```math
\int_1^2 f(x^3-3x)\,dx=\int_0^1 f(x^3-3x)\,dx.
```

<details>
<summary>展开参考解答</summary>

（1）令 $`g(x)=x^3-3x`$。它在 $`[-2,-1]`$、$`[-1,1]`$、$`[1,2]`$ 上分别严格递增、严格递减、严格递增，三段值域均为 $`[-2,2]`$。分别取反函数为 $`\varphi_1,\varphi_2,\varphi_3`$。它们连续，且在开区间内原函数导数不为零，因此连续可微。由 $`g`$ 为奇函数及各支的值域，立得两条对称关系。

（2）由 Vieta 公式，$`\varphi_1+\varphi_2+\varphi_3=0`$，故开区间上三者导数之和为零。因 $`f`$ 偶且 $`\varphi_1'(-t)=\varphi_3'(t)`$，


```math
2\int_{-2}^2f(t)\varphi_3'(t)\,dt
=-\int_{-2}^2f(t)\varphi_2'(t)\,dt.
```


又 $`\varphi_2'`$ 为偶函数，代换 $`t=g(x)`$ 得


```math
\int_1^2f(g(x))\,dx
=-\int_{-2}^0f(t)\varphi_2'(t)\,dt
=\int_0^1f(g(x))\,dx.
```


上述导数在端点处可能无界，换元积分按端点极限理解；各反函数单调且总变差有限，$`f`$ 有界，故所用反常积分绝对收敛。

</details>
