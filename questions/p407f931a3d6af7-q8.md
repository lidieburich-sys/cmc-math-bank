专题：[曲线积分与格林公式](../topics/line-integral.md)

## 题目

设曲线 $`\Gamma`$ 是


```math
x^2+y^2+z^2=1,\qquad x+z=1,\qquad x,y,z\ge0
```


上从 $`A(1,0,0)`$ 到 $`B(0,0,1)`$ 的一段。求


```math
I=\int_\Gamma y\,dx+z\,dy+x\,dz.
```

<details>
<summary>展开参考解答</summary>

取参数


```math
x=\frac{1+\cos t}2,\quad y=\frac{\sin t}{\sqrt2},\quad z=\frac{1-\cos t}2,\qquad0\le t\le\pi.
```


该方向正好由 $`A`$ 到 $`B`$。代入得


```math
\begin{aligned}
I&=\int_0^\pi\left[-\frac{\sin^2t}{2\sqrt2}+\frac{(1-\cos t)\cos t}{2\sqrt2}+\frac{(1+\cos t)\sin t}4\right]dt\\
&=\int_0^\pi\left[-\frac1{2\sqrt2}+\frac{\cos t}{2\sqrt2}+\frac{\sin t}4+\frac{\sin t\cos t}4\right]dt\\
&=\boxed{\frac12-\frac\pi{2\sqrt2}}.
\end{aligned}
```

</details>
