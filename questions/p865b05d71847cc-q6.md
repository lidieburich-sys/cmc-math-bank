## 题目

设 $`0<\alpha<1`$，正数列 $`a_n`$ 满足


```math
\lim_{n\to\infty}n^\alpha\left(\frac{a_n}{a_{n+1}}-1\right)=\lambda>0.
```


证明任意 $`k>0`$ 都有 $`n^ka_n\to0`$。

<details>
<summary>展开参考解答</summary>

由条件及 $`\ln(1+u)\sim u`$，存在 $`N`$ 与常数 $`c>0`$，使 $`n\ge N`$ 时


```math
\ln a_n-\ln a_{n+1}=\ln\frac{a_n}{a_{n+1}}\ge c n^{-\alpha}.
```


累加并比较积分，得


```math
\ln a_n\le C-c\sum_{j=N}^{n-1}j^{-\alpha}\le C'-c' n^{1-\alpha}
```


其中 $`c'>0`$。所以


```math
0<n^ka_n\le e^{C'}\exp(k\ln n-c'n^{1-\alpha})\to0,
```


因为 $`\ln n=o(n^{1-\alpha})`$。

</details>
