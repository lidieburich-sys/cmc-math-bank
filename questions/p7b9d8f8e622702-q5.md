## 题目

设 $`f(t)`$ 在 $`t\ne0`$ 时一阶连续可导，且 $`f(1)=0`$。求 $`f(x^2-y^2)`$，使曲线积分


```math
\int_L y[2-f(x^2-y^2)]\,dx+xf(x^2-y^2)\,dy
```


与路径无关，其中 $`L`$ 为任一不与直线 $`y=\pm x`$ 相交的分段光滑曲线。

<details>
<summary>展开参考解答</summary>

记 $`t=x^2-y^2`$，$`P=y[2-f(t)],Q=xf(t)`$。由 $`P_y=Q_x`$，得


```math
2-f(t)+2y^2f'(t)=f(t)+2x^2f'(t),
\qquad tf'(t)+f(t)=1.
```


即 $`[tf(t)]'=1`$，所以在每个连通区间上 $`f(t)=1+C/t`$。由 $`f(1)=0`$，正半轴上的常数为 $`-1`$。参考答案取两侧相同常数，得到一种满足条件的函数


```math
\boxed{f(x^2-y^2)=1-\frac1{x^2-y^2}.}
```


确实，此时积分形式等于


```math
d\left[xy-\frac12\ln\left|\frac{x+y}{x-y}\right|\right],
```


故在每个不跨越 $`y=\pm x`$ 的连通区域中与路径无关。

严格按题设，负半轴上的常数并未由 $`f(1)=0`$ 确定；完整解族为


```math
f(t)=\begin{cases}1-1/t,&t>0,\\1+C_-/t,&t<0,\end{cases}\qquad C_-\in\mathbb R.
```

</details>
