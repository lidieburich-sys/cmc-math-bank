## 题目

求微分方程的通解：



```math
(x^3-y^2)\,dx+(x^2y+xy)\,dy=0.
```

<details>
<summary>展开参考解答</summary>

在 $`x\notin\{0,-1\}`$ 的区间上，令 $`u=y^2`$，方程化为



```math
\frac{du}{dx}-\frac{2}{x(1+x)}u=-\frac{2x^2}{1+x}.
```



积分因子为 $`\mu(x)=\left(\frac{1+x}{x}\right)^2`$，因此



```math
\frac{d}{dx}\left[\left(\frac{1+x}{x}\right)^2u\right]=-2(1+x).
```



积分并代回 $`u=y^2`$，得通解



```math
\boxed{\left(\frac{1+x}{x}\right)^2y^2+(1+x)^2=C.}
```

</details>
