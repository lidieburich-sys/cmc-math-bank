## 题目

设 $`f(0)=0`$，$`x\ne0`$ 时 $`f(x)=x\sin(1/x)`$。求满足


```math
\sup_{x\ne y}\frac{|f(x)-f(y)|}{|x-y|^\alpha}<\infty
```


的最大常数 $`\alpha`$。

<details>
<summary>展开参考解答</summary>

答案为 $`\boxed{\alpha=1/2}`$。先证该指数可行。$`f`$ 为偶函数且 $`|f|\le1`$，故只需考虑 $`0\le x<y`$，记 $`\delta=y-x`$。$`\delta\ge1`$ 时差值不超过 $`2\le2\sqrt\delta`$。设 $`\delta<1`$。

若 $`x^2\le\delta`$，则


```math
|f(x)-f(y)|\le x+y=2x+\delta\le3\sqrt\delta.
```


若 $`x^2>\delta`$，由 $`|f'(t)|\le1+1/t`$ 和中值定理，


```math
|f(x)-f(y)|\le\delta(1+1/x)\le2\sqrt\delta.
```


对异号点，利用偶性和 $`\big||x|-|y|\big|\le|x-y|`$ 得到同一界。

若 $`\alpha>1/2`$，取 $`x_n=(n\pi)^{-1}`$、$`y_n=((n+1/2)\pi)^{-1}`$。此时 $`f(x_n)=0`$、$`|f(y_n)|=y_n`$，且 $`|x_n-y_n|\asymp n^{-2}`$，故比值 $`\asymp n^{2\alpha-1}\to\infty`$。

</details>
