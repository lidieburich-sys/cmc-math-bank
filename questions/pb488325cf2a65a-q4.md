## 题目

设椭球面


```math
\Sigma_1:\frac{x^2}{a^2}+\frac{y^2}{b^2}+\frac{z^2}{c^2}=1,\qquad a>b>c>0,
```


与圆锥面 $`\Sigma_2:z^2=x^2+y^2`$ 的交线为 $`\Gamma`$。求 $`\Sigma_1`$ 在 $`\Gamma`$ 各点的切平面到原点距离的最大值和最小值。

<details>
<summary>展开参考解答</summary>

切平面为 $`xX/a^2+yY/b^2+zZ/c^2=1`$，故其到原点距离满足


```math
d^{-2}=\frac{x^2}{a^4}+\frac{y^2}{b^4}+\frac{z^2}{c^4}.
```


在交线上 $`z^2=x^2+y^2`$，因此


```math
\left(\frac1{a^2}+\frac1{c^2}\right)x^2+\left(\frac1{b^2}+\frac1{c^2}\right)y^2=1.
```


记


```math
U_a=\frac{a^4+c^4}{a^2c^2(a^2+c^2)},\qquad U_b=\frac{b^4+c^4}{b^2c^2(b^2+c^2)}.
```


令 $`s=(a^{-2}+c^{-2})x^2\in[0,1]`$，可将距离写为 $`d^{-2}=sU_a+(1-s)U_b`$。所以极值必在 $`s=0`$ 或 $`s=1`$ 达到。设


```math
d_a=ac\sqrt{\frac{a^2+c^2}{a^4+c^4}},\qquad d_b=bc\sqrt{\frac{b^2+c^2}{b^4+c^4}},
```


则


```math
\boxed{d_{\min}=\min\{d_a,d_b\},\qquad d_{\max}=\max\{d_a,d_b\}}.
```


其中 $`d_a`$ 在 $`y=0`$、$`x^2=z^2=a^2c^2/(a^2+c^2)`$ 处达到；$`d_b`$ 在 $`x=0`$、$`y^2=z^2=b^2c^2/(b^2+c^2)`$ 处达到。如果 $`U_a=U_b`$，距离在整个交线上为常数。

</details>
