## 题目

证明方程 $`x=\tan\sqrt{x}`$ 有无穷多个正根，且全体正根可以按递增顺序排列为


```math
0<r_1<r_2<\cdots<r_n<\cdots.
```


对正数 $`\lambda`$，讨论级数


```math
\sum_{n=1}^{\infty}\bigl(\cot\sqrt{r_n}\bigr)^\lambda
```


的收敛性。

<details>
<summary>展开参考解答</summary>

令 $`t=\sqrt{x}>0`$，原方程等价于 $`\tan t=t^2`$。

先排除 $`0<t<\pi/2`$。在此区间，$`\tan t>t`$，从而


```math
\tan t=t+\int_0^t\tan^2s\,ds>t+\frac{t^3}{3}.
```


而


```math
t+\frac{t^3}{3}-t^2
=\frac t3\left[\left(t-\frac32\right)^2+\frac34\right]>0,
```


故该区间没有正根。在正切非正的区间也显然无根。

对每个整数 $`n\ge1`$，在 $`(n\pi,n\pi+\pi/2)`$ 上考察


```math
H(t)=\frac{\tan t}{t^2},\qquad
H'(t)=\frac{t-\sin(2t)}{t^3\cos^2t}>0,
```


因为 $`t>\pi>1\ge\sin(2t)`$。又 $`H(n\pi+)=0`$、$`H((n\pi+\pi/2)-)=+\infty`$，故该区间恰有一个 $`t_n`$ 满足 $`H(t_n)=1`$。这给出全部正根 $`r_n=t_n^2`$，且


```math
(n\pi)^2<r_n<\left(n\pi+\frac\pi2\right)^2.
```


所以正根严格递增且无穷多个，并有 $`r_n/(\pi^2n^2)\to1`$。

利用根方程，$`\cot\sqrt{r_n}=1/r_n>0`$，故


```math
\bigl(\cot\sqrt{r_n}\bigr)^\lambda=r_n^{-\lambda}
\sim\pi^{-2\lambda}n^{-2\lambda}.
```


由极限比较判别法，级数在 $`\boxed{\lambda>\frac12}`$ 时收敛，在 $`\boxed{0<\lambda\le\frac12}`$ 时发散。

此证明分别处理正切的各个连续分支，避免跨越渐近线使用 $`\tan t\ge t`$。

</details>
