## 题目

设 $`\varphi(x)`$ 具有连续导数，在围绕原点的任意光滑简单闭曲线 $`C`$ 上，曲线积分


```math
\oint_C\frac{2xy\,dx+\varphi(x)\,dy}{x^4+y^2}
```


的值为常数。

（1）设 $`L`$ 为正向闭曲线 $`(x-2)^2+y^2=1`$，证明


```math
\oint_L\frac{2xy\,dx+\varphi(x)\,dy}{x^4+y^2}=0;
```



（2）求 $`\varphi(x)`$；（3）设 $`C`$ 为围绕原点的光滑简单正向闭曲线，求上述曲线积分。

<details>
<summary>展开参考解答</summary>

记积分形式为 $`\omega=Pdx+Qdy`$。由题设，围绕原点的闭曲线作不经过原点的局部变形时，积分不变。将任意不含原点的小圆与一条绕原点的曲线用细通道连接，再令通道宽度趋零，得到该小圆上的积分为零。由 Green 公式和被积函数的连续性，处处有 $`Q_x=P_y`$（原点除外）。因此 $`\omega`$ 在不含原点的单连通区域内积分为零，特别是（1）的 $`L`$ 上积分为零。

（2）展开 $`Q_x=P_y`$，得


```math
\varphi'(x)(x^4+y^2)-4x^3\varphi(x)=2x^5-2xy^2.
```


比较 $`y^2`$ 的系数，得 $`\varphi'(x)=-2x`$，即 $`\varphi(x)=-x^2+K`$。代回常数项得 $`K=0`$，故 $`\boxed{\varphi(x)=-x^2}`$。

（3）由 Green 公式，任意正向绕原点曲线的积分等于 $`\Gamma:x^4+y^2=1`$ 上的积分；若两条曲线不相互包含，可先分别与一条足够大的曲线比较。在 $`\Gamma`$ 上分母为 1，故


```math
\oint_C\omega=\oint_\Gamma(2xy\,dx-x^2dy)
=\iint_{x^4+y^2\le1}(-4x)\,dx\,dy=\boxed0.
```

</details>
