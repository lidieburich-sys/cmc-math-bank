## 题目

设 $`\alpha>0`$，$`f`$ 在 $`[0,+\infty)`$ 上二阶可导，且


```math
\lim_{x\to+\infty}\frac{|f(x)|}{x^\alpha}=0,\qquad
\limsup_{x\to+\infty}x^\alpha|f''(x)|<+\infty.
```


（1）若 $`0<\alpha\le1`$，证明 $`\lim_{x\to+\infty}f'(x)=0`$；

（2）若 $`\alpha>1`$，构造满足上述条件、但当 $`x\to+\infty`$ 时 $`f'(x)\not\to0`$ 的函数，且其导数在任何非退化子区间上均不恒为常数。

<details>
<summary>展开参考解答</summary>

（1）取 $`M`$，使充分大的 $`t`$ 有 $`|f''(t)|\le Mt^{-\alpha}`$。任取 $`s>0`$，令 $`h=sx^\alpha`$。由泰勒公式，存在 $`\xi\in(x,x+h)`$，使


```math
f(x+h)=f(x)+hf'(x)+\frac12h^2f''(\xi).
```


故


```math
|f'(x)|\le\frac{|f(x+h)|+|f(x)|}{sx^\alpha}+\frac{Ms}{2}.
```


因 $`0<\alpha\le1`$，当 $`x\ge1`$ 时有 $`(x+h)/x\le1+s`$，结合 $`f(t)=o(t^\alpha)`$ 可知第一项趋于零。因此 $`\limsup|f'|\le Ms/2`$；令 $`s\to0^+`$，得 $`f'\to0`$。

（2）取


```math
f(x)=x+\int_0^x\frac{dt}{1+t^\alpha}.
```


当 $`\alpha>1`$ 时，积分有界，故 $`f=o(x^\alpha)`$。且


```math
f'(x)=1+\frac1{1+x^\alpha}\to1,\qquad f''(x)=-\frac{\alpha x^{\alpha-1}}{(1+x^\alpha)^2},\qquad x^\alpha|f''(x)|\to0.
```


$`f'`$ 在 $`(0,+\infty)`$ 严格递减，因而不在任何非退化子区间恒定，满足全部要求。

</details>
