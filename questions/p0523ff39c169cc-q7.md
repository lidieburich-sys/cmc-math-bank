## 题目

设 $`f`$ 在 $`[0,1]`$ 上连续，且 $`\int_0^1f(x)\,dx\ne0`$。证明存在三个不同的点 $`x_1,x_2,x_3\in[0,1]`$，使


```math
\begin{aligned}
\frac\pi8\int_0^1f(x)\,dx
&=\left[\frac1{1+x_1^2}\int_0^{x_1}f(t)\,dt+f(x_1)\arctan x_1\right]x_3\\
&=\left[\frac1{1+x_2^2}\int_0^{x_2}f(t)\,dt+f(x_2)\arctan x_2\right](1-x_3).
\end{aligned}
```

<details>
<summary>展开参考解答</summary>

记 $`A=\int_0^1f\ne0`$，令


```math
F(x)=\frac4{\pi A}\arctan x\int_0^xf(t)\,dt.
```


则 $`F(0)=0,F(1)=1`$。由介值定理存在 $`x_3\in(0,1)`$，使 $`F(x_3)=1/2`$。分别在 $`[0,x_3]`$、$`[x_3,1]`$ 上使用中值定理，存在


```math
x_1\in(0,x_3),\quad x_2\in(x_3,1),\quad F'(x_1)x_3=F'(x_2)(1-x_3)=\frac12.
```


又


```math
F'(x)=\frac4{\pi A}\left[\frac1{1+x^2}\int_0^xf(t)\,dt+f(x)\arctan x\right].
```


代入即得所需等式，三个点的所在区间保证它们不同。

</details>
