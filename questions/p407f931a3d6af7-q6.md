专题：[二重积分与三重积分](../topics/multiple.md)

## 题目

记曲面 $`z^2=x^2+y^2`$ 与 $`z=\sqrt{4-x^2-y^2}`$ 围成的空间区域为 $`V`$。求


```math
\iiint_V z\,dx\,dy\,dz.
```

<details>
<summary>展开参考解答</summary>

用球坐标 $`z=\rho\cos\varphi`$，区域为


```math
0\le\rho\le2,\quad0\le\varphi\le\frac\pi4,\quad0\le\theta\le2\pi.
```


因此


```math
\iiint_Vz\,dV
=\int_0^{2\pi}\!d\theta\int_0^{\pi/4}\sin\varphi\cos\varphi\,d\varphi\int_0^2\rho^3\,d\rho
=\boxed{2\pi}.
```

</details>
