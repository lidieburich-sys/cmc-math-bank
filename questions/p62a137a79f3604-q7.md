## 题目

已知 $`D=\{(x,y):0\le x\le\pi,\ 0\le y\le\pi\}`$，$`L`$ 为 $`D`$ 的正向边界。证明：

（1）


```math
\oint_L xe^{\sin y}\,dy-ye^{-\sin x}\,dx
=\oint_L xe^{-\sin y}\,dy-ye^{\sin x}\,dx;
```



（2）


```math
\oint_L xe^{\sin y}\,dy-ye^{-\sin x}\,dx\ge\frac52\pi^2.
```

<details>
<summary>展开参考解答</summary>

沿正方形四条边积分，两个曲线积分均等于


```math
\pi\int_0^\pi\left(e^{\sin t}+e^{-\sin t}\right)dt,
```


故（1）成立。由 $`e^u+e^{-u}\ge2+u^2`$，进一步得


```math
\pi\int_0^\pi\left(e^{\sin t}+e^{-\sin t}\right)dt
\ge\pi\int_0^\pi(2+\sin^2t)dt=\frac52\pi^2.
```


故（2）成立。

</details>
