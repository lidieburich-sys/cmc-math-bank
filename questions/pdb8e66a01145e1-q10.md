## 题目

设


```math
A_n(x,y)=\sum_{k=0}^{n}x^{n-k}y^k,\qquad0<x,y<1.
```


证明


```math
\frac2{2-x-y}\le\sum_{n=0}^{\infty}\frac{A_n(x,y)}{n+1}\le\frac12\left(\frac1{1-x}+\frac1{1-y}\right).
```

<details>
<summary>展开参考解答</summary>

由多项式积分恒等式，


```math
\frac{A_n(x,y)}{n+1}=\int_0^1[(1-t)x+ty]^n\,dt.
```


因 $`\max(x,y)<1`$，几何级数可在积分区间上一致求和，所以


```math
S=\int_0^1\frac{dt}{1-(1-t)x-ty}.
```


函数 $`H(s)=1/(1-s)`$ 在 $`(0,1)`$ 上凸。由凸性，


```math
H((1-t)x+ty)\le(1-t)H(x)+tH(y),
```


积分得上界 $`S\le[H(x)+H(y)]/2`$。又将 $`t`$ 与 $`1-t`$ 两处值相加，凸性给出


```math
H((1-t)x+ty)+H(tx+(1-t)y)\ge2H((x+y)/2).
```


积分得下界 $`S\ge H((x+y)/2)=2/(2-x-y)`$。两界均得证。

</details>
