## 题目

已知曲面


```math
S_1:17x^2+17y^2+8z^2+30xy+34x+30y-16z-7=0
```


所围成的区域被曲面


```math
S_2:17x^2+17y^2+30xy+34x+30y-32z+57=0
```


分成上下两部分。计算上部区域与下部区域的体积之比。

<details>
<summary>展开参考解答</summary>

作保持体积及上下关系的正交平移变换


```math
u=\frac{x-y+1}{\sqrt2},\qquad v=\frac{x+y+1}{\sqrt2},\qquad w=z-1.
```


两曲面化为


```math
S_1:\frac{u^2}{16}+v^2+\frac{w^2}4=1,\qquad S_2:w=\frac{u^2}{16}+v^2+\frac14.
```


令 $`u=4r\cos\theta,v=r\sin\theta`$。椭球上半面为 $`w=2\sqrt{1-r^2}`$，与抛物面的交线满足 $`2\sqrt{1-r^2}=r^2+1/4`$，解得 $`r^2=3/4`$。因此上部体积为


```math
\begin{aligned}
V_\text{上}&=8\pi\int_0^{\sqrt3/2}\left(2\sqrt{1-r^2}-r^2-\frac14\right)r\,dr\\
&=8\pi\left(\frac7{12}-\frac9{64}-\frac3{32}\right)=\frac{67\pi}{24}.
\end{aligned}
```


椭球总体积为 $`\frac43\pi\cdot4\cdot1\cdot2=32\pi/3`$，故下部体积为 $`189\pi/24`$，所求为 $`\boxed{67:189}`$。

</details>
