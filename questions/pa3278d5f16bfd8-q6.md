## 题目

设 $`x>-1`$ 时，可微函数 $`f`$ 满足


```math
f'(x)+f(x)-\frac1{1+x}\int_0^xf(t)\,dt=0,\qquad f(0)=1.
```


证明当 $`x\ge0`$ 时，$`e^{-x}\le f(x)\le1`$。

<details>
<summary>展开参考解答</summary>

令 $`x=0`$，得 $`f'(0)=-1`$。将等式乘以 $`1+x`$，再求导并整理，得


```math
(1+x)f''(x)+(2+x)f'(x)=0.
```


解得 $`f'(x)=Ce^{-x}/(1+x)`$。由初值得 $`C=-1`$，所以当 $`x\ge0`$ 时，


```math
f(x)=1-\int_0^x\frac{e^{-t}}{1+t}\,dt\le1.
```


又 $`e^{-t}/(1+t)\le e^{-t}\ (t\ge0)`$，故


```math
f(x)\ge1-\int_0^xe^{-t}\,dt=e^{-x}.
```

</details>
