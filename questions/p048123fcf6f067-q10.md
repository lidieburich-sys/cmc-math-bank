## 题目

设正项级数 $`\sum_{n=1}^{\infty}a_n`$ 收敛。证明：存在收敛的正项级数 $`\sum_{n=1}^{\infty}b_n`$，使


```math
\lim_{n\to\infty}\frac{a_n}{b_n}=0.
```

<details>
<summary>展开参考解答</summary>

记尾和 $`S_n=\sum_{k=n}^{\infty}a_k`$，则 $`S_n>0`$ 且 $`S_n\to0`$。构造


```math
b_n=\frac{a_n}{\sqrt{S_n}}>0.
```


由于 $`a_n=S_n-S_{n+1}`$，有


```math
b_n=(\sqrt{S_n}-\sqrt{S_{n+1}})\frac{\sqrt{S_n}+\sqrt{S_{n+1}}}{\sqrt{S_n}}
\le2(\sqrt{S_n}-\sqrt{S_{n+1}}).
```


望远镜求和得 $`\sum_{n=1}^{N}b_n\le2\sqrt{S_1}`$，故正项级数 $`\sum b_n`$ 收敛。同时


```math
\frac{a_n}{b_n}=\sqrt{S_n}\longrightarrow0,
```


即得所需级数。

</details>
