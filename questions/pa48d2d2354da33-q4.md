## 题目

已知


```math
\int_0^{+\infty}\frac{\sin x}{x}\,dx=\frac\pi2,
```


计算累次反常积分


```math
I=\int_0^{+\infty}\int_0^{+\infty}\frac{\sin x\sin(x+y)}{x(x+y)}\,dx\,dy.
```

<details>
<summary>展开参考解答</summary>

令


```math
F(t)=\int_0^t\frac{\sin u}{u}\,du,\qquad F(+\infty)=\frac\pi2.
```


先将外层 $`y`$ 积分截断至 $`R`$。此时带状区域上的积分绝对收敛，可交换积分次序，得到


```math
I_R=\int_0^\infty\frac{\sin x}{x}\,[F(x+R)-F(x)]\,dx.
```


分部积分给出 $`|F(t)-\pi/2|\le2/t`$。当 $`R\to\infty`$ 时，


```math
\left|\int_0^\infty\frac{\sin x}{x}\left[F(x+R)-\frac\pi2\right]dx\right|
\le\frac{2[1+\ln(1+R)]}{R}\longrightarrow0.
```


又因 $`F'(x)=\sin x/x`$，


```math
I=\frac\pi2\int_0^\infty F'(x)\,dx-\int_0^\infty F(x)F'(x)\,dx
=\frac{\pi^2}{4}-\frac12\left(\frac\pi2\right)^2
=\boxed{\frac{\pi^2}{8}}.
```

</details>
