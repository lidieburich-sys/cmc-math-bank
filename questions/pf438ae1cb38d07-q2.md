## 题目

设 $`s\ge0`$，


```math
\varphi(s)=\int_0^{+\infty}\frac{\ln(1+sx^2)}{x(1+x^2)}\,dx.
```


求 $`\varphi(1)`$ 和 $`\varphi(2)`$。

<details>
<summary>展开参考解答</summary>

依次作代换 $`t=x^2`$、$`u=t/(1+t)`$，得


```math
\varphi(s)=\frac12\int_0^1\frac{\ln\bigl(1+(s-1)u\bigr)-\ln(1-u)}{u}\,du.
```


对 $`s=1`$，利用 $`-\ln(1-u)=\sum_{n=1}^{\infty}u^n/n`$ 及非负项的逐项积分，得


```math
\varphi(1)=\frac12\sum_{n=1}^{\infty}\frac1n\int_0^1u^{n-1}\,du
=\frac12\sum_{n=1}^{\infty}\frac1{n^2}
=\boxed{\frac{\pi^2}{12}}.
```


对 $`s=2`$，由


```math
\ln(1+u)-\ln(1-u)=2\sum_{m=0}^{\infty}\frac{u^{2m+1}}{2m+1}\qquad(0\le u<1),
```


同样逐项积分得


```math
\varphi(2)=\sum_{m=0}^{\infty}\frac1{(2m+1)^2}
=\left(1-\frac14\right)\sum_{n=1}^{\infty}\frac1{n^2}
=\boxed{\frac{\pi^2}{8}}.
```

</details>
