## 题目

求下列极限。



```math
\lim_{x\to0}\frac{\ln(1+x^2)-x^2}{\sin^4x}
```

<details>
<summary>展开参考解答</summary>

```math
-\frac12
```



分母的主要量级是四阶。分子的二阶项会被减去，所以只写 $`\ln(1+t)\approx t`$ 不够。



```math
\sin^4x=x^4+o(x^4)
```





```math
\ln(1+t)=t-\frac{t^2}{2}+o(t^2)
```





```math
\ln(1+x^2)-x^2=-\frac{x^4}{2}+o(x^4)
```





```math
\frac{\ln(1+x^2)-x^2}{\sin^4x}=\frac{-\frac12+o(1)}{1+o(1)}\to-\frac12
```

</details>
