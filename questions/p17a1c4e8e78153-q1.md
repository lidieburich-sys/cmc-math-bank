## 题目

设马鞍面 $`S:x^2-y^2=2z`$，平面 $`\sigma:z=\alpha x+\beta y+\gamma`$，其中 $`\alpha,\beta,\gamma`$ 为常数。求 $`S`$ 上的点 $`P`$，使过 $`P`$ 且落在 $`S`$ 上的直线均平行于 $`\sigma`$。

<details>
<summary>展开参考解答</summary>

设 $`P=(a,b,c)`$，$`a^2-b^2=2c`$。过 $`P`$ 且方向为 $`(u,v,w)`$ 的直线完全落在 $`S`$ 上，当且仅当


```math
u^2-v^2=0,\qquad au-bv-w=0.
```


非零方向必须有 $`u\ne0`$，所以恰有两条母线，方向分别为 $`(1,1,a-b)`$、$`(1,-1,a+b)`$。二者方向均与平面法向量 $`(\alpha,\beta,-1)`$ 正交，给出


```math
a-b=\alpha+\beta,\qquad a+b=\alpha-\beta.
```


故 $`a=\alpha,b=-\beta`$，并由曲面方程得到


```math
\boxed{P=\left(\alpha,-\beta,\frac{\alpha^2-\beta^2}{2}\right)}.
```

</details>
