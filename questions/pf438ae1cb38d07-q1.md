## 题目

已知单叶双曲面


```math
S:\quad x^2+y^2-z^2=1.
```


（1）求 $`S`$ 上经过 $`M_0(1,-1,1)`$ 的两条不同族的直母线方程；

（2）求 $`S`$ 上相互垂直的直母线交点的轨迹。

<details>
<summary>展开参考解答</summary>

（1）设过 $`M_0`$ 的直母线为


```math
(x,y,z)=(1,-1,1)+t(a,b,c),\qquad (a,b,c)\ne(0,0,0).
```


代入曲面方程并比较 $`t,t^2`$ 的系数，得


```math
a-b-c=0,\qquad a^2+b^2-c^2=0.
```


故 $`c=a-b`$、$`ab=0`$，两条直母线为


```math
\boxed{L_1:(x,y,z)=(1,-1,1)+t(1,0,1)},
\qquad
\boxed{L_2:(x,y,z)=(1,-1,1)+t(0,1,-1)},\quad t\in\mathbb R.
```



（2）设交点为 $`P=(r\cos\theta,r\sin\theta,z)`$，其中 $`r=\sqrt{1+z^2}>0`$。取相互正交的单位向量


```math
\boldsymbol e_r=(\cos\theta,\sin\theta,0),\quad
\boldsymbol e_\theta=(-\sin\theta,\cos\theta,0),\quad
\boldsymbol e_z=(0,0,1).
```


若过 $`P`$ 的直母线方向为 $`a\boldsymbol e_r+b\boldsymbol e_\theta+c\boldsymbol e_z`$，则它须满足


```math
ra-zc=0,\qquad a^2+b^2-c^2=0.
```


非零方向必有 $`c\ne0`$，将其缩放使 $`c=r`$，便得 $`a=z`$、$`b=\pm1`$。因而两条直母线的方向可取


```math
\boldsymbol v_\pm=z\boldsymbol e_r\pm\boldsymbol e_\theta+r\boldsymbol e_z,
\qquad
\boldsymbol v_+\cdot\boldsymbol v_-=z^2-1+r^2=2z^2.
```


两条直母线垂直当且仅当 $`z=0`$。结合曲面方程，所求轨迹为


```math
\boxed{x^2+y^2=1,\qquad z=0}.
```
