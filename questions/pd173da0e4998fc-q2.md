## 题目

设 $`a_n`$ 递增，$`a_1>1`$。证明级数


```math
\sum_{n=1}^\infty\frac{a_{n+1}-a_n}{a_n\ln a_{n+1}}
```


收敛当且仅当 $`a_n`$ 有界。分母中的 $`a_n`$ 能否换成 $`a_{n+1}`$？

<details>
<summary>展开参考解答</summary>

若 $`a_n\le M`$，则正项部分和不超过 $`(M-a_1)/(a_1\ln a_1)`$，所以收敛。

反之，令 $`b_n=\ln a_n>0`$。由 $`\ln(1+u)\le u`$，


```math
\frac{b_{n+1}-b_n}{b_{n+1}}
\le\frac{a_{n+1}-a_n}{a_n\ln a_{n+1}}.
```


若 $`a_n`$ 无界，则 $`b_n\to\infty`$。对任意起点 $`N`$，可选 $`M>N`$，使 $`b_{M+1}\ge2b_N`$，于是


```math
\sum_{n=N}^M\frac{b_{n+1}-b_n}{b_{n+1}}
\ge\frac{b_{M+1}-b_N}{b_{M+1}}\ge\frac12.
```


这违反 Cauchy 收敛准则，故原级数也不能收敛，必要性成立。

不能将分母换为 $`a_{n+1}`$。反例取 $`a_n=e^{n^2}`$，它无界，但


```math
0<\frac{a_{n+1}-a_n}{a_{n+1}\ln a_{n+1}}<\frac1{(n+1)^2},
```


故修改后的级数收敛。

</details>
