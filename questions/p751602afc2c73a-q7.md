## 题目

求下列函数在 $`x_0=2`$ 处的 Taylor 级数，并确定其收敛域。



```math
f(x)=\frac1{(x-1)(x+3)}
```

<details>
<summary>展开参考解答</summary>

```math
\frac14\sum_{n=0}^{\infty}(-1)^n(1-\frac1{5^{n+1}})(x-2)^n,\quad1<x<3
```





```math
f(x)=\frac14\left(\frac1{x-1}-\frac1{x+3}\right)
```





```math
\frac1{x-1}=\frac1{1+(x-2)}
```





```math
\frac1{x+3}=\frac15\frac1{1+\frac{x-2}5}
```





```math
f(x)=\frac14\sum_{n=0}^{\infty}(-1)^n(1-\frac1{5^{n+1}})(x-2)^n
```





```math
|x-2|<1
```



$`x=1`$ 与 $`x=3`$ 时，级数通项都不趋于 0，因此两端点均发散。



```math
1<x<3
```

</details>
