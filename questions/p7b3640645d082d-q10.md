## 题目

设 $`f,g`$ 在 $`[a,b]`$ 上连续可导，满足


```math
\int_a^bf=\int_a^bg=0,\qquad f'(x)g(x)-f(x)g'(x)>0\quad(x\in[a,b]),
```


且 $`g`$ 在 $`(a,b)`$ 上有唯一零点 $`\xi`$。证明：

（1）$`\displaystyle\int_a^bf(x)\int_a^xg(s)\,ds\,dx=-\int_a^bg(x)\int_a^xf(s)\,ds\,dx`$；

（2）$`\displaystyle\int_a^bf(x)\int_a^xg(s)\,ds\,dx>0`$。

<details>
<summary>展开参考解答</summary>

（1）令 $`F(x)=\int_a^xf(s)ds,G(x)=\int_a^xg(s)ds`$。因两者在 $`a,b`$ 都为零，分部积分得 $`\int_a^bfG=-\int_a^bgF`$。

（2）记所求积分为 $`I`$。利用（1），有


```math
2I=\iint_{a\le s\le x\le b}[f(x)g(s)-f(s)g(x)]\,ds\,dx.
```


在 $`(a,\xi)`$、$`(\xi,b)`$ 上，$`g`$ 均不为零、各自保持同号，且


```math
\left(\frac fg\right)'=\frac{f'g-fg'}{g^2}>0.
```


因此在两个同侧三角区域 $`a<s<x<\xi`$、$`\xi<s<x<b`$ 上，核函数


```math
f(x)g(s)-f(s)g(x)=g(x)g(s)\left[\frac{f(x)}{g(x)}-\frac{f(s)}{g(s)}\right]>0.
```


余下的跨越 $`\xi`$ 的矩形部分积分为


```math
\left(\int_\xi^bf\right)\left(\int_a^\xi g\right)-\left(\int_\xi^bg\right)\left(\int_a^\xi f\right)=0,
```


因为全区间的两个积分都是零。故 $`2I>0`$，结论成立。

</details>
