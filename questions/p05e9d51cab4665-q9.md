## 题目

设 $`(T_n)_{n\ge1}`$ 独立同分布，均服从参数为 $`1`$ 的指数分布。定义


```math
S_0=0,\quad S_n=T_1+\cdots+T_n\ (n\ge1),\qquad
N_t=\max\{n\ge0:S_n\le t\}\ (t\ge0).
```


（1）求 $`S_n`$ 的分布函数及 $`N_t`$ 的分布列。

（2）对 $`f\in L^1([0,1])`$，证明


```math
\mathbb E\!\left(\int_0^1f(s)\,dN_s\right)
=\mathbb E\!\left(\sum_{n=1}^{\infty}f(S_n)\mathbf1_{\{S_n\le1\}}\right)
=\int_0^1f(s)\,ds.
```


（3）据此构造计算 $`\int_0^1f(s)\,ds`$ 的蒙特卡洛算法。

<details>
<summary>展开参考解答</summary>

（1）$`S_n`$ 为 $`n`$ 个指数变量之和。由密度卷积归纳得


```math
p_n(s)=\frac{s^{n-1}e^{-s}}{(n-1)!}\quad(s\ge0),
```


因此其分布函数在 $`t<0`$ 时为零，在 $`t\ge0`$ 时为


```math
\boxed{F_{S_n}(t)=1-e^{-t}\sum_{j=0}^{n-1}\frac{t^j}{j!}.}
```


对 $`k\ge1`$，由 $`S_k`$ 与 $`T_{k+1}`$ 独立，


```math
\mathbb P(N_t=k)=\int_0^tp_k(s)e^{-(t-s)}\,ds
=e^{-t}\frac{t^k}{k!}.
```


$`k=0`$ 时同样由 $`\mathbb P(T_1>t)=e^{-t}`$ 得到该式，故 $`\boxed{N_t\sim\operatorname{Poisson}(t)}`$。

（2）$`N_s`$ 在各 $`S_n`$ 处跳跃 $`1`$，所以 Stieltjes 积分等于题中的随机和。由非负项交换定理，


```math
\begin{aligned}
\mathbb E\sum_{n\ge1}|f(S_n)|\mathbf1_{\{S_n\le1\}}
&=\int_0^1|f(s)|e^{-s}\sum_{n\ge1}\frac{s^{n-1}}{(n-1)!}\,ds\\
&=\int_0^1|f(s)|\,ds<\infty.
\end{aligned}
```


因此可对 $`f`$ 用 Fubini 定理，去掉绝对值即得所求等式。

（3）独立模拟 $`M`$ 条轨道。每条轨道依次取独立均匀变量 $`U_j\in(0,1)`$，令 $`T_j=-\ln U_j`$，累加成 $`S_n`$；首次超过 $`1`$ 时停止，记录


```math
Y=\sum_{S_n\le1}f(S_n).
```


用 $`\widehat I_M=M^{-1}\sum_{j=1}^MY_j`$ 估计积分。上一步说明 $`Y`$ 可积且期望等于该积分，因此估计无偏，并由强大数定律几乎处处收敛到积分。

</details>
