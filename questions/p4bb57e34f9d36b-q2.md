## 题目

设实二次型 $`f(x)=x^TAx`$，其中


```math
A=\begin{pmatrix}2&a_0&2&-2\\a&0&b&c\\d&e&0&f\\g&h&k&4\end{pmatrix},
```


所有字母为实数。已知 $`2`$ 为 $`A`$ 的几何重数为 $`3`$ 的特征值。

（1）$`A`$ 能否相似于对角矩阵？说明理由。

（2）当 $`a_0=2`$ 时，求二次型在正交变换下的标准形。

<details>
<summary>展开参考解答</summary>

（1）$`\operatorname{tr}A=6`$。特征值 $`2`$ 的代数重数至少为 $`3`$，不可能为 $`4`$（否则迹为 $`8`$），故恰为 $`3`$，另一特征值为 $`0`$。两个特征子空间维数分别为 $`3`$、$`1`$，所以 $`A`$ 有四个线性无关特征向量，$`\boxed{A\text{ 可对角化}}`$。

（2）由 $`\dim\ker(A-2I)=3`$，有 $`\operatorname{rank}(A-2I)=1`$。令所有行与第一行 $`(0,2,2,-2)`$ 成比例，得到


```math
A=\begin{pmatrix}2&2&2&-2\\0&0&-2&2\\0&-2&0&2\\0&-2&-2&4\end{pmatrix}.
```


二次型的对称矩阵为


```math
B=\frac{A+A^T}2=\begin{pmatrix}2&1&1&-1\\1&0&-2&0\\1&-2&0&0\\-1&0&0&4\end{pmatrix}.
```


其特征多项式为 $`(\lambda-2)^2(\lambda^2-2\lambda-11)`$，特征值为 $`2,2,1+2\sqrt3,1-2\sqrt3`$。由实对称矩阵的正交对角化，标准形为


```math
\boxed{f=2y_1^2+2y_2^2+(1+2\sqrt3)y_3^2+(1-2\sqrt3)y_4^2}.
```

</details>
