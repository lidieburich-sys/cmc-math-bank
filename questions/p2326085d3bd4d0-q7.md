## 题目

设 $`f`$ 在 $`[0,1]`$ 上有二阶导数，存在正常数 $`A,B`$，使


```math
|f(x)|\le A,\qquad |f^{\prime\prime}(x)|\le B.
```


证明：对任意 $`x\in[0,1]`$，都有 $`|f^{\prime}(x)|\le2A+B/2`$。

<details>
<summary>展开参考解答</summary>

对 $`0<x<1`$，以 $`x`$ 为展开点，分别展开到端点：


```math
f(0)=f(x)-xf^{\prime}(x)+\frac12f^{\prime\prime}(\xi)x^2,
```




```math
f(1)=f(x)+(1-x)f^{\prime}(x)+\frac12f^{\prime\prime}(\eta)(1-x)^2,
```


其中 $`0<\xi<x<\eta<1`$。相减并整理得


```math
f^{\prime}(x)=f(1)-f(0)-\frac12f^{\prime\prime}(\eta)(1-x)^2+\frac12f^{\prime\prime}(\xi)x^2.
```


故


```math
|f^{\prime}(x)|\le2A+\frac B2\big((1-x)^2+x^2\big)\le2A+\frac B2.
```


当 $`x=0`$ 或 $`x=1`$ 时，直接以相应端点为中心展开到另一端点，也得到同一估计。

</details>
