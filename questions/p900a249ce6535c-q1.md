## 题目

给定三个平面


```math
\pi_1:x+y+z+1=0,\quad\pi_2:x+\lambda y+\mu z-1=0,\quad\pi_3:x+\lambda^2y+\mu^2z=0,
```


其中 $`\lambda,\mu\in\mathbb R`$。求三个平面交于唯一一点的条件，并求交点坐标。

<details>
<summary>展开参考解答</summary>

系数矩阵是 Vandermonde 型矩阵，其行列式为


```math
\begin{vmatrix}1&1&1\\1&\lambda&\mu\\1&\lambda^2&\mu^2\end{vmatrix}
=(\lambda-1)(\mu-1)(\mu-\lambda).
```


线性方程组有唯一解当且仅当该行列式非零，故所求条件是


```math
\boxed{\lambda\ne1,\qquad\mu\ne1,\qquad\lambda\ne\mu.}
```


后两式分别减第一式，记 $`U=(\lambda-1)y`$、$`V=(\mu-1)z`$，得


```math
U+V=2,\qquad(\lambda+1)U+(\mu+1)V=1.
```


由此求出 $`U,V`$，再由 $`x=-1-y-z`$，得到交点


```math
\boxed{\begin{aligned}
x&=-\frac{\lambda\mu+\lambda+\mu}{(\lambda-1)(\mu-1)},\\
y&=-\frac{2\mu+1}{(\lambda-\mu)(\lambda-1)},\\
z&=\frac{2\lambda+1}{(\lambda-\mu)(\mu-1)}.
\end{aligned}}
```

</details>
