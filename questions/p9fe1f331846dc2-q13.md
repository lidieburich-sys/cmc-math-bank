## 题目

设独立随机变量序列 $`\{X_n\}_{n\ge1}`$ 满足


```math
P(X_n=n^\theta)=P(X_n=-n^\theta)=\frac12,\qquad\theta>0.
```


记 $`S_n=\sum_{i=1}^nX_i`$。

（1）当 $`\theta<1/2`$ 时，证明 $`S_n/n`$ 依概率收敛于 $`0`$；

（2）证明 $`S_n/\sqrt{\operatorname{Var}(S_n)}`$ 依分布收敛于标准正态分布。

<details>
<summary>展开参考解答</summary>

有 $`EX_i=0`$、$`EX_i^2=i^{2\theta}`$，由独立性，


```math
s_n^2=\operatorname{Var}(S_n)=\sum_{i=1}^ni^{2\theta}\sim\frac{n^{2\theta+1}}{2\theta+1}.
```


（1）任意 $`\varepsilon>0`$，由切比雪夫不等式，


```math
P(|S_n/n|\ge\varepsilon)\le\frac{s_n^2}{\varepsilon^2n^2}\longrightarrow0\quad(\theta<1/2).
```


（2）检验四阶 Lyapunov 条件：


```math
\frac{\sum_{i=1}^nE|X_i|^4}{s_n^4}
=\frac{\sum_{i=1}^ni^{4\theta}}{(\sum_{i=1}^ni^{2\theta})^2}
\sim\frac{(2\theta+1)^2}{(4\theta+1)n}\longrightarrow0.
```


故由独立但不必同分布变量的 Lyapunov 中心极限定理，$`S_n/s_n`$ 依分布趋于 $`N(0,1)`$。

</details>
