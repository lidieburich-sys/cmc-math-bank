## 题目

设 $`\mathcal S`$ 为所有无穷次可微复值函数 $`\varphi:\mathbb R\to\mathbb C`$ 中满足


```math
\sup_{x\in\mathbb R}|x^m\varphi^{(k)}(x)|<\infty\qquad(m,k\ge0)
```


的函数类。对 $`f\in\mathcal S`$，定义 $`\widehat f(x)=\int_{\mathbb R}f(y)e^{-2\pi ixy}\,dy`$。证明 $`\widehat f\in\mathcal S`$，且


```math
f(x)=\int_{\mathbb R}\widehat f(y)e^{2\pi ixy}\,dy.
```

<details>
<summary>展开参考解答</summary>

所有多项式乘以 $`f`$ 及其导数均绝对可积，因此可任意次在积分号下求导，得到


```math
\widehat f^{(k)}(x)=\int_{\mathbb R}(-2\pi iy)^kf(y)e^{-2\pi ixy}\,dy.
```


令 $`h_k(y)=(-2\pi iy)^kf(y)`$，分部积分 $`m`$ 次（边界项由快速下降消失）给出


```math
(2\pi ix)^m\widehat f^{(k)}(x)=\int_{\mathbb R}h_k^{(m)}(y)e^{-2\pi ixy}\,dy.
```


右端绝对值不超过 $`\|h_k^{(m)}\|_1`$，故每个 $`x^m\widehat f^{(k)}`$ 均有界，即 $`\widehat f\in\mathcal S`$。

为证明反演，取 $`\varepsilon>0`$，利用可直接由高斯积分算出的恒等式


```math
\int_{\mathbb R}e^{-\pi\varepsilon\xi^2}e^{2\pi iu\xi}\,d\xi=\varepsilon^{-1/2}e^{-\pi u^2/\varepsilon}.
```


由 Fubini 定理，


```math
\int_{\mathbb R}\widehat f(\xi)e^{-\pi\varepsilon\xi^2}e^{2\pi ix\xi}\,d\xi=\int_{\mathbb R}f(t)\varepsilon^{-1/2}e^{-\pi(x-t)^2/\varepsilon}\,dt.
```


右端是质量为 $`1`$ 的高斯近似恒等核与 $`f`$ 的卷积，由连续性和有界性趋于 $`f(x)`$。左端由 $`\widehat f\in L^1`$ 及控制收敛定理，趋于 $`\int\widehat f(\xi)e^{2\pi ix\xi}d\xi`$。比较极限即得反演公式。

</details>
