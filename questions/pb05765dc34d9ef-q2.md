## 题目

设 $`s\ge0`$，


```math
\varphi(s)=\int_0^{+\infty}\frac{\ln(1+sx^2)}{x(1+x^2)}\,dx.
```


求 $`\varphi(1)`$ 和 $`\varphi(2)`$。

<details>
<summary>展开参考解答</summary>

取 $`t=x^2/(1+x^2)`$，则


```math
\frac{dx}{x(1+x^2)}=\frac{dt}{2t},\qquad
\ln(1+sx^2)=\ln(1+(s-1)t)-\ln(1-t).
```


因此


```math
\varphi(1)=-\frac12\int_0^1\frac{\ln(1-t)}t\,dt
=\frac12\sum_{n=1}^\infty\frac1{n^2}
=\boxed{\frac{\pi^2}{12}}.
```


同理，利用


```math
\ln\frac{1+t}{1-t}=2\sum_{k=0}^\infty\frac{t^{2k+1}}{2k+1}\qquad(0\le t<1),
```


得到


```math
\varphi(2)=\frac12\int_0^1\frac{\ln(1+t)-\ln(1-t)}t\,dt
=\sum_{k=0}^\infty\frac1{(2k+1)^2}
=\boxed{\frac{\pi^2}{8}}.
```


两次逐项积分均可由非负项的单调收敛定理保证；端点的对数奇性可积，故这些反常积分均收敛。

</details>
