## 题目

单位圆 $`\Gamma`$ 的外切 $`n`$ 边形各边依次切圆于 $`B_1,\ldots,B_n`$。记外切多边形周长为 $`P_A`$，接触点组成的内接多边形周长为 $`P_B`$。证明


```math
P_A^{1/3}P_B^{2/3}>2\pi.
```

<details>
<summary>展开参考解答</summary>

令相邻切点的圆心角的一半为 $`\alpha_i\in(0,\pi/2)`$，则 $`\sum_i\alpha_i=\pi`$，且


```math
P_A=2\sum_i\tan\alpha_i,\qquad P_B=2\sum_i\sin\alpha_i.
```


先证 $`0<x<\pi/2`$ 时 $`\tan^{1/3}x\sin^{2/3}x>x`$。令 $`g(x)=\sin x/\cos^{1/3}x-x`$，有 $`g(0)=0`$，且由算术—几何平均不等式，


```math
g^{\prime}(x)=\frac{2\cos^2x+1}{3\cos^{4/3}x}-1>0.
```


所以所证单项不等式严格成立。再用 Hölder 不等式，


```math
P_A^{1/3}P_B^{2/3}=2\left(\sum_i\tan\alpha_i\right)^{1/3}\left(\sum_i\sin\alpha_i\right)^{2/3}\ge2\sum_i\tan^{1/3}\alpha_i\sin^{2/3}\alpha_i>2\sum_i\alpha_i=2\pi.
```

</details>
