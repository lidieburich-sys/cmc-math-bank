## 题目

设 $`L_1,L_2`$ 是空间中两条不垂直的异面直线，$`B`$ 是公垂线段的中点。点 $`A_1,A_2`$ 分别在两直线上滑动，且 $`A_1B\perp A_2B`$。证明直线 $`A_1A_2`$ 的轨迹是单叶双曲面。

<details>
<summary>展开参考解答</summary>

取 $`B`$ 为原点、公垂线为 $`z`$ 轴，适当取 $`x,y`$ 轴，可写


```math
L_1:y=-ax,z=c,\qquad L_2:y=ax,z=-c,
```


其中 $`c>0,a\ne0,a^2\ne1`$。设两动点为 $`(u,-au,c),(v,av,-c)`$。正交条件给出 $`(1-a^2)uv=c^2`$。直线上任意点可写


```math
x=tu+(1-t)v,\quad y=-atu+a(1-t)v,\quad z=c(2t-1).
```


消元得


```math
\boxed{(1-a^2)x^2-\frac{1-a^2}{a^2}y^2+z^2=c^2.}
```


当 $`a^2<1`$ 或 $`a^2>1`$ 时，该式均有两个正平方项、一个负平方项，故为单叶双曲面。严格说，有限的 $`A_1,A_2`$ 给出的母线并未覆盖该曲面的两个极限母线；例如在 $`z=c`$ 上还存在 $`y=ax`$ 的母线，而原动直线在这一平面只能经过 $`L_1`$。因而按参考答案的通常几何约定，取轨迹的闭包得到整个单叶双曲面；若不取闭包，原题“轨迹是整个曲面”的字面断言需作上述修正。

</details>
