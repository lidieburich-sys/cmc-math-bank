## 题目

讨论广义积分 

```math
\int_0^{+\infty}\frac{x}{\cos^2x+x^\alpha\sin^2x}\,dx
```

 的敛散性，其中 $`\alpha`$ 为实常数。

<details>
<summary>展开参考解答</summary>

在 $`0`$ 附近，$`\cos^2x\ge1/2`$，所以被积函数不超过 $`2x`$，下限没有收敛问题。

当 $`\alpha\le0`$ 且 $`x\ge1`$ 时，分母不超过 $`1`$，故积分发散。设 $`\alpha>0`$，记


```math
A_n=\int_{n\pi}^{(n+1)\pi}\frac{x\,dx}{\cos^2x+x^\alpha\sin^2x}.
```


由 $`n\pi\le x\le(n+1)\pi`$ 及恒等式


```math
\int_0^\pi\frac{dt}{\cos^2t+B\sin^2t}=\frac\pi{\sqrt B}\qquad(B>0),
```


可得


```math
\frac{n\pi^2}{((n+1)\pi)^{\alpha/2}}\le A_n\le\frac{(n+1)\pi^2}{(n\pi)^{\alpha/2}}.
```


所以 $`A_n`$ 与 $`n^{1-\alpha/2}`$ 同阶，由正项级数比较判别法，原积分恰在 $`1-\alpha/2<-1`$ 时收敛。因此


```math
\boxed{\alpha>4\text{ 时收敛；}\quad\alpha\le4\text{ 时发散。}}
```

</details>
