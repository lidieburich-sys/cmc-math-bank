## 题目

考虑单叶双曲面 $`S:x^2-y^2+z^2=1`$。

（1）证明同一族直母线中任意两条不同的直母线为异面直线。

（2）同一族中的两条不同直母线分别经过 $`M_1=(1,1,1)`$、$`M_2=(2,2,1)`$。求两直线的公垂线方程和距离。

<details>
<summary>展开参考解答</summary>

（1）两族直母线分别可以参数化为


```math
(x,y,z)=(\cos\theta,0,\sin\theta)+t(-\sigma\sin\theta,1,\sigma\cos\theta),
\quad \sigma=1\ \text{或}\ -1.
```


固定 $`\sigma`$ 即固定一族。若两条同族母线相交，由 $`y=t`$ 可知交点参数 $`t`$ 相同，再由


```math
x+iz=(1+i\sigma t)e^{i\theta}
```


知两角相同模 $`2\pi`$，故两直线相同。又两方向向量的第二分量都是 1，平行也会推出两角相同。因此不同的同族母线既不相交也不平行，必为异面直线。

（2）经过两点且不同的同族母线为


```math
L_1:\ \begin{cases}x+y-z=1,\\x-y+z=1,\end{cases}
\quad
L_2:\ \begin{cases}x+y-2z=2,\\2x-2y+z=1.\end{cases}
```


可分别取方向向量 $`d_1=(0,1,1)`$、$`d_2=(3,5,4)`$。另一族经过两点的是同一条直线 $`z=1,x=y`$，故不符合两条不同母线的条件。

公垂线方向为 $`n=d_1\times d_2=(-1,3,-3)`$。分别通过 $`M_1,M_2`$ 且由 $`(d_1,n)`$、$`(d_2,n)`$ 张成的平面相交得到公垂线：


```math
\boxed{\begin{cases}6x+y-z=6,\\27x-5y-14z=30.\end{cases}}
```


距离为


```math
\boxed{d=\frac{|(M_2-M_1)\cdot n|}{\|n\|}=\frac2{\sqrt{19}}}.
```

</details>
