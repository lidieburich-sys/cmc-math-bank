## 题目

设 $`(R,+,\cdot)`$ 是含 $`1\ne0`$ 的结合环，$`a,b\in R`$，且 $`a+b=ba`$。若关于 $`x`$ 的方程组


```math
\begin{cases}x^2-(ax^2+x^2a)+ax^2a=1,\\x+a-(ax+xa)+axa=1\end{cases}
```


在 $`R`$ 中有解，证明 $`ab=ba`$。

<details>
<summary>展开参考解答</summary>

记 $`c=1-a`$，则方程组等价于 $`cx^2c=1,cxc=c`$。由结合律，


```math
cx=cx(cx^2c)=(cxc)x^2c=cx^2c=1,
```




```math
xc=(cx^2c)xc=cx^2(cxc)=cx^2c=1.
```


故 $`c`$ 可逆，逆为 $`x`$。由 $`a+b=ba`$，


```math
(1-b)c=1-a-b+ba=1.
```


于是 $`1-b=c^{-1}`$，也有 $`c(1-b)=1`$，即 $`1-a-b+ab=1`$，得到 $`ab=a+b=ba`$。

</details>
