## 题目

设 $`c\in(0,1)`$、$`x_1\in(0,1)`$，且 $`x_1\ne c(1-x_1^2)`$。定义


```math
x_{n+1}=c(1-x_n^2),\qquad n\ge1.
```


证明 $`\{x_n\}`$ 收敛当且仅当 $`c\in(0,\sqrt3/2]`$。

<details>
<summary>展开参考解答</summary>

记 $`F(x)=c(1-x^2)`$，它将 $`[0,1]`$ 映入 $`[0,c]`$，且严格递减。$`F(x)=x`$ 的唯一非负解为


```math
r=\frac{-1+\sqrt{1+4c^2}}{2c}.
```


因为 $`F`$ 单射且 $`x_1\ne r`$，所有 $`x_n\ne r`$。设 $`L=\limsup x_n`$、$`\ell=\liminf x_n`$，连续性与单调性给出 $`L=c(1-\ell^2)`$、$`\ell=c(1-L^2)`$。若 $`L>\ell`$，则相减得 $`L+\ell=1/c`$，于是 $`L,\ell`$ 是方程


```math
cs^2-s+\frac1c-c=0
```


的两个不同实根，其判别式为 $`4c^2-3>0`$。因此当 $`c\le\sqrt3/2`$ 时必有 $`L=\ell`$，数列收敛。

反之，当 $`c>\sqrt3/2`$ 时，$`|F'(r)|=\sqrt{1+4c^2}-1>1`$。若数列收敛，则只能收敛到 $`r`$。取 $`r`$ 的一个小邻域，使其中 $`|F'|>1`$。对充分大的 $`n`$，中值定理得


```math
|x_{n+1}-r|>|x_n-r|>0,
```


这与距离趋于零矛盾，故此时数列发散。

</details>
