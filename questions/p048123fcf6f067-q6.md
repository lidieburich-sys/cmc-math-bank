## 题目

记向量 $`\overrightarrow{OA}`$ 与 $`\overrightarrow{OB}`$ 的夹角为 $`\alpha`$，且


```math
|\overrightarrow{OA}|=1,\qquad |\overrightarrow{OB}|=2,\qquad
\overrightarrow{OP}=(1-\lambda)\overrightarrow{OA},\quad
\overrightarrow{OQ}=\lambda\overrightarrow{OB},\quad0\le\lambda\le1.
```


（1）当 $`\lambda`$ 为何值时，$`|\overrightarrow{PQ}|`$ 取得最小值？

（2）设（1）中的 $`\lambda`$ 满足 $`0<\lambda<1/5`$，求夹角 $`\alpha`$ 的取值范围。

<details>
<summary>展开参考解答</summary>

（1）记 $`c=\cos\alpha\in[-1,1]`$。由余弦定理，


```math
F(\lambda)=|\overrightarrow{PQ}|^2=(1-\lambda)^2+4\lambda^2-4\lambda(1-\lambda)c
=(5+4c)\lambda^2-2(1+2c)\lambda+1.
```


由于 $`5+4c>0`$，无约束极小点为 $`(1+2c)/(5+4c)`$。结合 $`0\le\lambda\le1`$，真正的最小点为


```math
\boxed{\lambda_{\min}=\begin{cases}
\dfrac{1+2\cos\alpha}{5+4\cos\alpha},&0\le\alpha\le2\pi/3,\\[4pt]
0,&2\pi/3<\alpha\le\pi.
\end{cases}}
```


（2）$`0<\lambda_{\min}<1/5`$ 排除了边界最小点，因此


```math
0<\frac{1+2c}{5+4c}<\frac15
\quad\Longleftrightarrow\quad-\frac12<c<0.
```


因而 $`\boxed{\pi/2<\alpha<2\pi/3}`$。

</details>
