## 题目

已知可导函数 $`f`$ 满足


```math
f(x)\cos x+2\int_0^xf(t)\sin t\,dt=x+1.
```


求 $`f(x)`$。

<details>
<summary>展开参考解答</summary>

令 $`x=0`$ 得 $`f(0)=1`$。对等式求导，得


```math
f'(x)\cos x+f(x)\sin x=1.
```


在 $`\cos x\ne0`$ 的区间上，$`(f/\cos x)'=\sec^2x`$，故 $`f(x)=\sin x+C\cos x`$。初值给出 $`C=1`$；跨越 $`\cos x=0`$ 的各点时，可导性使相邻区间中的常数一致。所以


```math
\boxed{f(x)=\sin x+\cos x.}
```

</details>
