## 题目

计算三重积分


```math
I=\iiint_\Omega\frac{dx\,dy\,dz}{(1+x^2+y^2+z^2)^2},\qquad\Omega=\{0\le x,y,z\le1\}.
```

<details>
<summary>展开参考解答</summary>

利用 $`x,y`$ 对称性，在三角区域 $`0\le y\le x\le1`$ 上改用极坐标，得


```math
I=2\int_0^1\int_0^{\pi/4}\int_0^{\sec\theta}\frac{r\,dr\,d\theta\,dz}{(1+r^2+z^2)^2}
=\frac{\pi^2}{16}-J,
```


其中


```math
J=\int_0^{\pi/4}\int_0^1\frac{dz\,d\theta}{1+\sec^2\theta+z^2}.
```


令 $`z=\tan t`$，可得


```math
J=\int_0^{\pi/4}\int_0^{\pi/4}\frac{\sec^2t}{\sec^2\theta+\sec^2t}\,dt\,d\theta.
```


交换 $`t,\theta`$ 后两种被积式之和为 $`1`$，因此 $`2J=(\pi/4)^2`$，即 $`J=\pi^2/32`$。故 $`\boxed{I=\pi^2/32}`$。

</details>
