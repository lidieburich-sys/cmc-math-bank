## 题目

设 $`n\ge2`$、$`A\in\mathbb R^{n\times n}`$，规定 $`A^0=I`$，并形式定义


```math
\sin A=\sum_{k=0}^\infty\frac{(-1)^kA^{2k+1}}{(2k+1)!},\quad
\cos A=\sum_{k=0}^\infty\frac{(-1)^kA^{2k}}{(2k)!},
\quad\arctan A=\sum_{k=0}^\infty\frac{(-1)^kA^{2k+1}}{2k+1}.
```


令 $`\|A\|=\max_{\|x\|=1}\|Ax\|`$。证明：

（1）任意 $`A`$ 的 $`\sin A,\cos A`$ 均有意义，并且 $`(\sin A)^2+(\cos A)^2=I`$。

（2）若 $`\|A\|<1`$，则 $`\arctan A`$ 有意义，且


```math
\sin(\arctan A)=A\cos(\arctan A).
```

<details>
<summary>展开参考解答</summary>

（1）由次乘性 $`\|A^k\|\le\|A\|^k`$，两级数分别由标量指数级数控制，因此绝对收敛。所有项均为同一矩阵的幂，彼此交换；故可作 Cauchy 乘积。其各次幂系数与标量恒等式 $`\sin^2z+\cos^2z=1`$ 完全相同，从而矩阵恒等式成立。

（2）当 $`\|A\|<1`$ 时，反正切级数由 $`\sum\|A\|^{2k+1}/(2k+1)`$ 控制，绝对收敛。令


```math
B(t)=\arctan(tA),\quad R(t)=(I+t^2A^2)^{-1},\quad0\le t\le1.
```


一致收敛允许逐项求导，得 $`B'(t)=AR(t)`$；所有出现的矩阵均可交换。令


```math
F(t)=\sin B(t)-tA\cos B(t).
```


逐项求导并整理得到


```math
F'(t)=tA^2R(t)F(t),\qquad F(0)=0.
```


$`R`$ 在 $`[0,1]`$ 连续，线性微分方程解的唯一性（或 Gronwall 不等式）给出 $`F\equiv0`$。取 $`t=1`$ 即得所证。

</details>
