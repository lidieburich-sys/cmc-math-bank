## 题目

设 $`f,g`$ 在 $`\mathbb R`$ 上具有二阶连续导数，$`f(0)=g(0)=1`$。对 $`xOy`$ 平面内任意简单闭曲线 $`C`$，均有


```math
\oint_C[y^2f(x)+2ye^x-8yg(x)]dx+2[yg(x)+f(x)]dy=0.
```


求 $`f(x),g(x)`$。

<details>
<summary>展开参考解答</summary>

所有简单闭曲线上的积分为零，故由 Green 公式得 $`P_y=Q_x`$，即


```math
y[g'(x)-f(x)]+f'(x)+4g(x)-e^x=0.
```


比较关于 $`y`$ 的系数，得 $`g'=f`$、$`f'+4g=e^x`$，从而


```math
g''+4g=e^x,\qquad g(0)=1,\quad g'(0)=1.
```


解得


```math
\boxed{g(x)=\frac45\cos2x+\frac25\sin2x+\frac15e^x},
```




```math
\boxed{f(x)=g'(x)=-\frac85\sin2x+\frac45\cos2x+\frac15e^x}.
```

</details>
