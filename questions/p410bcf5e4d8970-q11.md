## 题目

设 $`a_1>0`$、$`\alpha>0`$，数列 $`\{a_n\}`$ 由递推式


```math
a_{n+1}=a_n+\left(\frac n{S_n}\right)^\alpha,\qquad S_n=a_1+a_2+\cdots+a_n,\quad n=1,2,\ldots
```


定义，并已知 $`\displaystyle\lim_{n\to\infty}\frac{na_n}{S_n}`$ 收敛。
（1）证明 $`\displaystyle\lim_{n\to\infty}\frac{a_n^{\alpha+1}}n`$ 收敛；
（2）求 $`\displaystyle\lim_{n\to\infty}\frac{na_n}{S_n}`$。

<details>
<summary>展开参考解答</summary>

记 $`B_n=na_n/S_n\to A`$。递推式说明 $`a_n`$ 严格递增，故 $`B_n\ge1`$、$`A\ge1`$。若 $`a_n\le M`$，则每个增量 $`(n/S_n)^\alpha\ge M^{-\alpha}>0`$，矛盾，故 $`a_n\to+\infty`$。又


```math
\frac{a_{n+1}-a_n}{a_n}=\frac{B_n^\alpha}{a_n^{\alpha+1}}\to0,
```


所以 $`a_{n+1}/a_n\to1`$。由中值定理，存在 $`\xi_n\in(a_n,a_{n+1})`$，满足


```math
a_{n+1}^{\alpha+1}-a_n^{\alpha+1}=(\alpha+1)\xi_n^\alpha\left(\frac n{S_n}\right)^\alpha=(\alpha+1)\left(\frac{\xi_n}{a_n}\right)^\alpha B_n^\alpha\to(\alpha+1)A^\alpha.
```


因此 Stolz 定理给出


```math
L:=\lim\frac{a_n^{\alpha+1}}n=(\alpha+1)A^\alpha>0,
```


证明（1）。再对 $`na_n/S_n`$ 使用 Stolz 定理（$`S_n\to+\infty`$），得


```math
A=\lim\frac{(n+1)a_{n+1}-na_n}{a_{n+1}}=1+\lim\frac{n(a_{n+1}-a_n)}{a_{n+1}}=1+\frac{A^\alpha}{L}=1+\frac1{\alpha+1}.
```


故（2）的答案为 $`\boxed{(\alpha+2)/(\alpha+1)}`$，且（1）的极限为 $`(\alpha+1)((\alpha+2)/(\alpha+1))^\alpha`$。

</details>
