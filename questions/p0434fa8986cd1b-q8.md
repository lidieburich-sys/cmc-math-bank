## 题目

设 $`R=[0,1]^2`$、$`R_\varepsilon=[0,1-\varepsilon]^2`$，定义


```math
I_\varepsilon=\iint_{R_\varepsilon}\frac{dx\,dy}{1-xy},\qquad I=\lim_{\varepsilon\to0^+}I_\varepsilon.
```


（1）证明 $`I=\sum_{n=1}^{\infty}1/n^2`$。

（2）利用变换 $`u=(x+y)/2`$、$`v=(y-x)/2`$ 计算 $`I`$，从而推出 $`\sum_{n=1}^{\infty}1/n^2=\pi^2/6`$。

<details>
<summary>展开参考解答</summary>

（1）在 $`R_\varepsilon`$ 上几何级数一致收敛，可逐项积分：


```math
I_\varepsilon=\sum_{k=0}^\infty\left(\int_0^{1-\varepsilon}x^k\,dx\right)^2=\sum_{n=1}^\infty\frac{(1-\varepsilon)^{2n}}{n^2}.
```


由 $`\sum1/n^2`$ 收敛及一致控制，令 $`\varepsilon\to0^+`$，得所证等式。

（2）反变换为 $`x=u-v`$、$`y=u+v`$，雅可比绝对值为 $`2`$，积分区域满足 $`0\le u\le1`$、$`|v|\le\min(u,1-u)`$。由对称性先对 $`v`$ 积分，得


```math
I=4\int_0^{1/2}\frac{\arctan(u/\sqrt{1-u^2})}{\sqrt{1-u^2}}\,du+4\int_{1/2}^1\frac{\arctan((1-u)/\sqrt{1-u^2})}{\sqrt{1-u^2}}\,du.
```


其中第一个反正切为 $`\arcsin u`$，第二个为 $`\tfrac12\arccos u`$。因此


```math
I=2(\arcsin(1/2))^2+(\arccos(1/2))^2=\frac{\pi^2}{18}+\frac{\pi^2}{9}=\boxed{\frac{\pi^2}6}.
```


结合（1）即得级数的和。

</details>
