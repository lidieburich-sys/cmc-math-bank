## 题目

求曲面 $`x^2+y^2=az`$ 和 $`z=2a-\sqrt{x^2+y^2}`$（$`a>0`$）所围立体的表面积。

<details>
<summary>展开参考解答</summary>

记 $`r=\sqrt{x^2+y^2}`$。交线满足 $`r^2/a=2a-r`$，非负解为 $`r=a`$，此时 $`z=a`$。

抛物面部分的面积为


```math
S_1=2\pi\int_0^a r\sqrt{1+\frac{4r^2}{a^2}}\,dr=\frac{\pi a^2}{6}(5\sqrt5-1).
```


圆锥面部分的斜率绝对值为 $`1`$，面积为


```math
S_2=2\pi\int_0^a\sqrt2\,r\,dr=\sqrt2\pi a^2.
```


因此总表面积为


```math
\boxed{S=\pi a^2\left(\frac{5\sqrt5-1}6+\sqrt2\right)}.
```

</details>
