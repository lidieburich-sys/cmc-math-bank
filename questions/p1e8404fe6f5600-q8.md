## 题目

设 $`\varphi:(0,\infty)\to(0,\infty)`$ 严格递减且连续，$`\lim_{t\to0^+}\varphi(t)=\infty`$，并且


```math
\int_0^\infty\varphi(t)dt=\int_0^\infty\varphi^{-1}(t)dt=a<\infty.
```


证明


```math
\int_0^\infty[\varphi(t)]^2dt+\int_0^\infty[\varphi^{-1}(t)]^2dt\ge\frac12a^{3/2}.
```

<details>
<summary>展开参考解答</summary>

令 $`p=\sqrt a`$，$`D=\{(x,y):x>0,\ 0<y<\varphi(x)\}`$，则 $`D`$ 的面积为 $`a`$。因为 $`\varphi`$ 递减，


```math
p\varphi(p)\le\int_0^p\varphi(t)dt\le a=p^2,
```


故 $`\varphi(p)\le p`$。因此 $`D`$ 中的两部分 $`x>p`$ 与 $`y>p`$ 不相交，其面积之和不超过 $`a`$，即


```math
P:=\int_p^\infty\varphi(t)dt,\quad Q:=\int_p^\infty\varphi^{-1}(t)dt,
\qquad P+Q\le a.
```


由 Cauchy 不等式（若平方积分无穷则结论显然），


```math
\begin{aligned}
\int_0^\infty\varphi^2+\int_0^\infty(\varphi^{-1})^2
&\ge\frac1p\left[\left(\int_0^p\varphi\right)^2+\left(\int_0^p\varphi^{-1}\right)^2\right]\\
&=\frac{(a-P)^2+(a-Q)^2}{p}\\
&\ge\frac{(2a-P-Q)^2}{2p}\ge\frac{a^2}{2p}=\frac12a^{3/2}.
\end{aligned}
```

</details>
