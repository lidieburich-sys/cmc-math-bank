## 题目

计算曲线积分


```math
I=\oint_\Gamma(y^2+z^2)\,dx+(z^2+x^2)\,dy+(x^2+y^2)\,dz,
```


其中 $`\Gamma`$ 是


```math
\begin{cases}
x^2+y^2+z^2=2Rx,\\
x^2+y^2=2rx,
\end{cases}
\qquad 0<r<R,\quad z\ge0
```


确定的闭曲线，其方向与 $`z`$ 轴正向符合右手螺旋法则。

<details>
<summary>展开参考解答</summary>

取球面 $`x^2+y^2+z^2=2Rx`$ 的上半部中由 $`\Gamma`$ 围成的曲面 $`S`$，选向上的外法向


```math
\boldsymbol n=\frac1R(x-R,y,z).
```


它在 $`xy`$ 平面的投影为圆盘 $`D=\{x^2+y^2\le2rx\}`$。对向量场
$`\boldsymbol F=(y^2+z^2,z^2+x^2,x^2+y^2)`$，有


```math
\nabla\times\boldsymbol F=(2y-2z,2z-2x,2x-2y),
\qquad (\nabla\times\boldsymbol F)\cdot\boldsymbol n=2(z-y).
```


由 Stokes 公式与 $`S`$ 关于 $`xz`$ 平面的对称性，得


```math
I=2\iint_S(z-y)\,dS=2\iint_S z\,dS.
```


在 $`z>0`$ 的部分，$`z\,dS=R\,dx\,dy`$；边界原点可用截去小邻域后取极限处理。因此


```math
I=2R\iint_Ddx\,dy=\boxed{2\pi Rr^2}.
```

</details>
