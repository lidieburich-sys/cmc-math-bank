## 题目

考虑常微分方程初值问题 $`y'=f(x,y),y(x_0)=y_0`$ 的两步格式


```math
y_n+a_1y_{n-1}+a_2y_{n-2}=h(b_0f_n+b_1f_{n-1}+b_2f_{n-2}),
```


其中 $`f_j=f(x_j,y_j)`$，$`a_1,a_2,b_0,b_1,b_2`$ 为常数。

（1）确定这些常数，使格式阶数尽可能高；

（2）分析所得格式的稳定性与收敛性。

<details>
<summary>展开参考解答</summary>

（1）将精确解在 $`x_n`$ 处展开，要求 $`y,y',\ldots,y^{(4)}`$ 的系数同时为零，得到


```math
1+a_1+a_2=0,\qquad a_1+2a_2+b_0+b_1+b_2=0,
```




```math
a_1+2^ja_2+jb_1+j2^{j-1}b_2=0\quad(j=2,3,4).
```


解得


```math
\boxed{a_1=0,\ a_2=-1,\ b_0=b_2=1/3,\ b_1=4/3}.
```


下一阶条件的左端为 $`4/3\ne0`$，故最高为四阶。格式为


```math
\boxed{y_n-y_{n-2}=\frac h3(f_n+4f_{n-1}+f_{n-2})}.
```


（2）第一特征多项式为 $`\rho(\zeta)=\zeta^2-1`$，两个根 $`\pm1`$ 均为单根且模为 $`1`$，所以零稳定。又 $`\rho(1)=0`$，且 $`\rho'(1)=\sigma(1)=2`$，其中 $`\sigma(\zeta)=(\zeta^2+4\zeta+1)/3`$，因此相容。由线性多步法等价定理，在标准 Lipschitz 条件及相容的初始值下，该格式收敛；以四阶初值启动可达到四阶全局精度。

</details>
