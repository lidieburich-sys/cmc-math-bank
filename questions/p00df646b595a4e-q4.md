## 题目

求幂级数 

```math
\sum_{n=1}^{\infty}\frac{2n-1}{2^n}x^{2n-2}
```

 的和函数，并求数项级数 

```math
\sum_{n=1}^{\infty}\frac{2n-1}{2^{2n-1}}
```

 的和。

<details>
<summary>展开参考解答</summary>

当 $`|x|<\sqrt2`$ 时，逐项积分得


```math
\int_0^x S(t)\,dt=\sum_{n=1}^{\infty}\frac{x^{2n-1}}{2^n}=\frac{x}{2-x^2}.
```


所以和函数为


```math
\boxed{S(x)=\frac{2+x^2}{(2-x^2)^2},\qquad -\sqrt2<x<\sqrt2}.
```


两端点的通项均不趋于零，因此不收敛。数项级数的和为


```math
\boxed{S\!\left(\frac1{\sqrt2}\right)=\frac{10}{9}}.
```

</details>
