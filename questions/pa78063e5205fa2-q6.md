## 题目

设


```math
x_1=2021,\qquad x_n^2-2(x_n+1)x_{n+1}+2021=0\quad(n\ge1).
```


证明数列 $`\{x_n\}`$ 收敛，并求 $`\displaystyle\lim_{n\to\infty}x_n`$。

<details>
<summary>展开参考解答</summary>

令 $`y_n=x_n+1`$，则


```math
y_1=2022,\qquad y_{n+1}=\frac{y_n}{2}+\frac{1011}{y_n}.
```


记 $`c=\sqrt{2022}`$。当 $`y_n>c`$ 时，


```math
y_{n+1}-c=\frac{(y_n-c)^2}{2y_n}>0,\qquad
y_{n+1}-y_n=\frac{2022-y_n^2}{2y_n}<0.
```


由归纳法，$`\{y_n\}`$ 严格递减且有下界 $`c`$，故收敛。设极限为 $`L\ge c`$，在递推式中取极限得 $`L=L/2+1011/L`$，从而 $`L=c`$。所以


```math
\boxed{\lim_{n\to\infty}x_n=\sqrt{2022}-1}.
```

</details>
